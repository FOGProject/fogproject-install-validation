# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## This repo has been retired

All GitHub Actions workflows that used to live here (`reusable_distro_workflow.yml`, the
`distro_*.yml` wrappers, `not-release-required-distros/`, and `run_all_distros.yml`) have moved
to [FOGProject/fog-workflows](https://github.com/FOGProject/fog-workflows), which now hosts all
of FOG Project's centralized release-automation and install-validation workflows in one place.

This repo is expected to be archived. If you're looking for the distro install-validation
logic, go there instead — its `CLAUDE.md` documents the moved workflows.
